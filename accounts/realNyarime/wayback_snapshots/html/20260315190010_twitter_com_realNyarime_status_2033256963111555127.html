给 AI Agent 用的限额虚拟卡？: https://t.co/YUBN5Uxyap

这玩意不是传统的充值卡台，它的逻辑是：
绑你自己的付款卡 → 命令行/AI开一张限额虚拟卡 → 丢给 AI 去付款(未实现的场景估计没有支付网关会允许)。支持 MCP，所有兼容 MCP 的 Agent 都可以直接调用。

官网里的流程基本是：
1. npm install -g agent-cards
2. agent-cards signup
3. agent-cards setup-mcp

之后 Agent 就可以做这些事：
• 创建卡
• 查余额
• 列卡列表
• 取卡详情
• 关闭卡

实测了一下：
• 最低开卡额度 1 USD
• 首次开卡需要填
姓名 / 生日 / 手机号
• 需要绑定 payment method（Stripe）
• 卡能成功开出来(开1刀的扣了1刀)，状态 OPEN
• 可查卡详情、余额、交易记录，也可以关闭卡。
• 敏感操作都有邮件提醒
• 帮大家试了，能过GPT验卡

其实就是：
不给 AI 真实的卡，而是让AI调用MCP生成可控额度的虚拟卡。
这样未来Agent就算乱用，最多也只会花你给它的那点额度 👀

目前还是 beta(暂时也没啥应用场景)：

• 0开卡费
