GPT-5.6 模型在 Responses API 中支持 standard（标准） 和 pro（专业） 两种推理模式
默认模式为 standard。对于需要模型投入更多计算、且可以接受更高延迟和更多 Token 消耗的复杂任务，可将 reasoning.mode 设置为 pro

推理模式（reasoning mode）与推理强度（reasoning effort）彼此独立。reasoning.mode 用于选择 standard 或 pro 执行模式，而 reasoning.effort 则控制模型在所选模式下投入多少推理工作。如果省略 reasoning.effort，GPT-5.6 在两种模式下均默认使用 medium
