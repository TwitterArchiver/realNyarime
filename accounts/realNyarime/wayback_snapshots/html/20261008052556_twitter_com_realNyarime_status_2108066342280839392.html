OpenAI 28天冲刺Day 3：GPT-6进Chat，付费用户再送一次额度重置

OpenAI 产品与平台主管 Thibault Sottiaux 公布 28 天产品冲刺的 Day 3。当天最大的更新是 GPT-6 正式进入 ChatGPT 聊天界面，率先向 Plus、Pro、Business 和 Enterprise 用户开放，Free 和 Go 随后跟进。Work 和 Codex 使用的模型这次没有变化。

他同时宣布，Codex 和 ChatGPT Work 合计活跃用户达到 4000 万的新高。为了庆祝这个节点，OpenAI 还会给所有付费账户发放一次 banked reset（额度重置卡）。它不会立即重置额度，用户可以在一个月有效期内自行选择使用时间。
