前阵子给手机装了个rustdesk搞的被96110反诈折磨得死去活来，对于升级HyperOS无法root的米粉来说，还可以借助adb永久禁止系统应用联网。需要用到GitHub上的两个项目：
1）iamr0s/Dhizuku
需要设备管理员权限激活Dhizuku
2）BinTianqi/OwnDroid
再用Dhizuku授权OwnDroid

授权好后，打开OwnDroid，应用程序-禁用计量数据，添加需要禁用的程序，就可以禁用应用在移动数据流量下的联网权限，UID为1000的系统应用同样可以禁用。

要想让在WiFi情况下也生效，需要使用adb权限修改WIFI的网络类型，把WiFi类型修改为计量数据。
先用adb shell cmd netpolicy list wifi-networks查看已连接WiFi的信息，在获取到WiFi的SSID名称后，再用adb shell cmd netpolicy set metered-network “TP-LINK_3916“ true（引号改成自己的WiFi名称）即可把该WiFi的添加上计量数据属性。
唯一的缺点就是，添加该属性后任务栏的WiFi图标可能就变成移动热点的那种造型。
