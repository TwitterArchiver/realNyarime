根据最新的社区讨论和泄露信息（集中在 2026 年 4 月左右的 OpenAI Codex 平台相关的曝光），这些代号主要是 OpenAI 内部的实验性模型、垂直领域特化模型或尚在测试阶段的架构。

以下是对这些未公开（或刚刚公开）代号的调查结果：
🧬 生命科学与医药领域
GPT-Rosalind：这其实是一个刚刚被正式披露的专用模型。它是 OpenAI 为生命科学、药物研发和基因组学专门构建的推理模型，主要面向企业级科研团队。其命名致敬了对发现 DNA 双螺旋结构做出巨大贡献的化学家罗莎琳德·富兰克林（Rosalind Franklin）。
heisenberg（海森堡）：被认为就是 GPT-Rosalind 在发布前的内部开发代号，或者是该生命科学模型系列中的一个前沿实验分支。

🐕 趣味代号与实验性前沿模型
arcanine（风速狗）：这是一个内部的实验性前沿模型。在泄露的 UI 描述中，它被幽默地标记为 “对淀粉有着传奇般胃口的前沿模型 (Frontier model with legendary appetite for starches)”。这大概率是开发团队内部的恶搞备注，通常不建议用于生产环境。

🧊 冰川系列 (高强度推理/安全模型)
glacier-alpha：被描述为 “能够移动大陆的智能 (intelligence that moves continents)”。社区推测这是一个具备极高推理能力或高强度 Agentic（代理执行）能力的实验性大模型。
glacier-alpha-block-cy3 / cy4：被描述为 “冰冷的智能 (ice-cold intelligence)”。名字中的 “cy” 后缀被广泛推测为 Cyber（网络安全） 的缩写，意味着这些可能是专门针对代码审计、漏洞挖掘、威胁建模等网络安全任务进行微调（Fine-tuned）的冰川变体模型。

💻 内部架构测试
oai-2.1：描述为 “最新的前沿代理编程模型 (Latest frontier agentic coding model)”。“oai” 显然是 OpenAI 的缩写。这通常是某种新架构或内部测试族的名字，在获得正式的“GPT-5.x”命名之前，供内部开发者和受信任的测试人员用来测试代码生成能力。

总的来说，这些出现在列表里的名字，说明您（或者截图的最初来源）可能触发了某个内部测试通道的 UI 错误，或者是通过特定 API 绕过限制看到了 OpenAI 的后台实验模型库。
